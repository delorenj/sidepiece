Historical artifact — superseded by DESIGN.md

This is the origin mock for direction 04, “Deliberately Foreign”, rendered 2026-09-20 and picked by Jarad the same day. It is kept because the chosen register was born here, not because any number in it is current.

It is drawn at 340px with a pre-final token set. The design width was ruled at 320px on 2026-09-22 and the usable column is 284px. Every measurement, hex value, type size and string on this page has been superseded — including ink-3 #837A69 (dropped), the 8.5px chrome labels (raised to 10.5/11.5px), the tear-off perforation (now registration ticks), and DISPATCHED CMD (the abbreviation was refused; the full term fits).

For what Sidepiece actually looks like, read DESIGN.md and key-screens.html. The spines win on conflict with this mock.

Direction 04 · Deliberately Foreign

It is never mistaken for the page.

Sidepiece is the only tool Jarad owns that draws on other people’s screens, and the instant its marks are ambiguous with the page’s own, the finger-on-the-clipboard loop breaks — he points, and he isn’t sure what he pointed at.

So it gets a register of its own that carries everywhere: a paper sheet laid on the page, set entirely in serif because web chrome is sans, ruled in ink, and signed with a fluorescent spot that appears in virtually no production UI. Panel, hover outline and comment bubble share one perforated spine and one set of crop marks, so a Sidepiece mark reads as ours on a white docs site and on a black dashboard alike — which is what breaking dark-first and breaking no-shadows buys.

Honest at 340px — what fit, and what gave

  • Fits. The full clone path on one line at 10.5px mono (29 chars in a 300px column, 174px used) — no truncation, no tooltip, and user-select:all so one click takes the whole thing into a terminal.
  • Fits. Both classification values spelled out side by side, 300px column, 8px letterspaced mono. “Dispatched Command” did not — it is set as DISPATCHED CMD. That abbreviation is the one string in the mock that is not the PRD’s literal, and it is a real finding, not a preference.
  • Fits. The FR-10 context block prints the page title and the full URL unelided (47 chars × 9.5px mono = 268px of 300).
  • Gave. The perforated spine eats 10px and the sheet border 2px, so the usable column is 300px, not 340. That is the cost of the signature, paid on every surface, and it is the strongest argument against this direction.
  • Gave. Ticket rows carry the Backlog glyph ▫ rather than the word, because four repetitions of “Backlog” is density for nothing. The group header is position:sticky, so the state is on screen at every scroll position — the glyph never has to be remembered.
  • Gave. Ticket titles wrap to two lines at 12.5px in the 231px title column. Four tickets and the create line come to 214px of height. Truncating them was the alternative and it is worse — SIDE-12’s title is the only thing distinguishing it from SIDE-15.
