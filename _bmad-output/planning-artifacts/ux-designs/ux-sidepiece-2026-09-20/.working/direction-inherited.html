33GOD Inherited "it belongs to the platform" — Holocene's navy, Holocene's 1px structure, Holocene's severity language, with its two known defects fixed instead of copied.

Sidepiece is the fourth surface in a fleet, not a new product, so it wears Holocene's shipped navy verbatim — the same #0b1020 ground, the same structure built from 1px #26324d borders, the same zero shadows — and finally uses the severity language Holocene designed in September and never shipped: a hue never appears without its glyph, and green means exactly one thing.

The two inherited defects are handled, not reproduced. Holocene's own audit calls its stylesheet "three unreconciled palettes in one file", so the rgba-white neutral ramp and the whole Catppuccin accent set are dropped and one navy ramp governs every pixel here; and the type system stops being fiction — Inter is gone (you banned it by name as "the default safe font. Zero character.") and an MV3 extension can bundle IBM Plex as a packaged woff2, which is exactly the @font-face Holocene's Next app never got.

The argument is boring on purpose: open Sidepiece and Holocene in adjacent tabs and there should be no question they came out of the same shop.

What it inherits, unchanged

  • The navy ramp itself — #0b1020 / #121a2d / #26324d / #eef3ff / #9aa8c7, straight out of shipped globals.css. Deep navy, never neutral black; the hue is the signature.
  • 8px radius, 6px on chips, and zero shadows — layering is background lightness plus a 1px border, nothing else.
  • "Sans for people, mono for machines, never mixed inside one value." The dispatch receipt is entirely machine register; the PM's answer is entirely human.
  • "Density comes from leading, not from shrinking type" — 12.5px body at 1.62 line-height, and 10.5px used only for static chrome that meets 4.5:1.

What it refuses to inherit

  • The rgba-white ramp and the Catppuccin set #8aadf4 #ed8796 #a6da95 #f5a97f. One palette or it happens again.
  • Inter, and the 8-scale type system that never rendered. First name in the stack is the family the extension bundles; second name is verified installed on this machine today.
  • The six-rung ladder. Sidepiece has four states worth a hue, so #ff5f6d and #ff9152 go and #ff7a90 covers failure alone.
  • #5d6b8a — 3.6:1 on the base. The fleet's own rule kills it; #7c89a6 is the dim floor.
  • Blue is amended out of the ladder into the single interactive accent, which is the only way the law "no rung hue on chrome or controls" survives contact with a panel that has links in it.

What 340px actually costs

  • Nothing was cut. The clone path measures 193px at 11.5px mono in a 314px content box — about 120px to spare, so it stays one selectable line.
  • The page title is the only truncation in the design — one line with an ellipsis, with the URL beneath it whole, because the URL is the part that disambiguates.
  • Ticket rows go two lines rather than truncating: key and state on the chrome line, title in full below. Four rows cost 210px; the other 40 stay in Plane.
  • The classifier fits as two labelled halves at 11.5px with both literal values visible — no dropdown, no icon standing in for a word.
  • The honest loss is vertical: chat and Board cannot both be on screen. The Board is below the fold in steady state, which is the right answer for a product whose counter-metric is time spent in the panel.
