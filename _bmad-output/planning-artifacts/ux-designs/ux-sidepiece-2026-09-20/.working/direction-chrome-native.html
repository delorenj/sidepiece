Chrome Native — “it is part of the browser”

The Cockpit docks a few pixels from DevTools, so it is built out of the browser’s own parts: Chrome’s UI font, VS Code’s greys, structure from 1px rules, no shadow, no radius past 2px, and not one pixel of brand. Nothing here asks to be re-oriented to, which is the whole claim against SM-C1 — if entering the panel costs nothing, dipping in stays cheap and dwelling never starts. The one place this direction must break its own rule is v2: when Sidepiece draws into someone else’s page it will read as DevTools and get dismissed by reflex, so the in-page layer takes the single accent the panel itself refuses.

The v2 question, answered

Looking like browser chrome is right inside the dock and wrong outside it. When the annotation layer draws a hover outline into a page Jarad does not own, DevTools’ inspect overlay is already using that exact language on that exact pixel — and he runs DevTools constantly, so a grey-and-blue outline is one he dismisses by reflex and cannot attribute. So the rule is: no brand in the panel, one hue in the page. #ff9800 is held in reserve for the in-page layer alone — still drawn from the same neutral kit, deliberately not DevTools’ blue, and the only colour in the product that means “Sidepiece drew this.” The invisibility is the panel’s job, not the overlay’s.
