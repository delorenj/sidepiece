# Sidepiece annotations — SIDE-49

Build: `pnpm --filter @sidepiece/annotation build`; install `demo/sidepiece.user.js` in Tampermonkey. Host `demo/` over HTTP (`python3 -m http.server 8765 -d packages/annotation/demo`) or open the published demo. Click **Enable on this origin** and reload, then click **Sidepiece**. On any other site explicitly add its exact origin in console: `localStorage.setItem('sidepiece:allowed-origins', JSON.stringify([location.origin]))`, reload, and click the launcher. The `@match` wildcard only makes installation portable: the origin allowlist is empty by default and no launcher or overlay appears without opt-in.

Choose Jarad or Damian and a tool; start drawing, drag on page, enter a note before marking. Notes and immutable per-mark author/time are persisted to origin + path localStorage. Escape leaves drawing mode. Hide marks, undo and delete are local. Export `.sidepiece.json` is versioned, with page URL, document/viewport size, version hint (`meta[name=sidepiece-version]`), anchors, text snippets, screenshot asset references, notes and author. A screenshot is **not captured** from arbitrary tabs: if desired, manually capture a screenshot and click **Reference screenshot**; this stores its filename/reference only, not pixels, and you must keep the image alongside JSON. Future server-side S3 integration can resolve asset references. No image is uploaded and no secret is present in browser code. Import validates file, refuses mismatched URL/version/document size, then explicitly asks merge or replace. No cross-page overlay silently attaches. Markdown is deterministic, ordered by time/id, with author, target and geometry; core `markdown(doc, authorId)` filters per author. Copy uses clipboard or export `.md`.

Slack button calls `sendSlack` with no adapter, reports unconfigured and **does not send**. The reusable core accepts a mock adapter for tests; a real server-side adapter and an authorized Slack destination remain open dependencies. S3/MinIO asset storage is likewise only an optional server seam, not wired. No LLM, direct provider credential or realtime service.

Verification: `pnpm --filter @sidepiece/annotation test`, `pnpm --filter @sidepiece/annotation build`, `node packages/annotation/test/browser.mjs`, `pnpm typecheck`, `pnpm build`. Browser smoke drives Chromium on two URLs and two personas. Bridge integration tests require Node 24.15.x; use `mise exec node@24.15.0 -- pnpm test` rather than Node 26.
